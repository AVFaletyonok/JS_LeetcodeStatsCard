# Leetcode stats card

If you would like to add your coding statistics from leetcode.com like on this website,  
this project is for you)

Use next reference: https://jsleetcodestatscard.vercel.app/api/leetcode-stats-card?username=Your_nickname&theme=dark&borders=false.

You can use next flags:
- theme: dark / white;
- borders: true / false.
